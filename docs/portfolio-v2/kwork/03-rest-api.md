# Настрою загрузку данных из REST API в Excel или CSV

Превращу JSON-ответ вашего сервиса в таблицу с понятными столбцами. Настрою метод, параметры запроса и выбор массива записей, проверю статус ответа и выгрузку на согласованном примере.

## Что получит заказчик

- Настройку запроса и сопоставление полей JSON со столбцами итогового файла.
- Проверочный пример с ожидаемым числом записей и контрольным идентификатором.
- Инструкцию для повторного получения данных и выгрузки в XLSX, CSV или JSON.

## Что прислать

Ссылку на документацию API, адрес тестового источника или пример ответа, названия нужных полей и правила пагинации. Для заказа достаточно обезличенного JSON и описания типа авторизации. Рабочие токены и пароли вводятся у вас в браузере при запуске.

## Как выглядит проверка

В веб-версии шаблон «Доставки через API» запрашивает демонстрационный JSON с шестью отправлениями. Запись `TR-1051` из массива `data.shipments` превращается в строку реестра. Контрольные поля — два грузовых места и стоимость доставки 680 ₽. Если рабочий источник отдаёт несколько страниц, при приёмке также проверяем последнюю запись следующей страницы.

## Условия

Для прямого подключения из браузера источник должен разрешать CORS для адреса приложения и нужных заголовков. При закрытом API сначала согласуем доступ на стороне владельца. Периодическое получение данных рассчитано на открытую вкладку. Запись и удаление через API выполняются по отдельному согласованию.
