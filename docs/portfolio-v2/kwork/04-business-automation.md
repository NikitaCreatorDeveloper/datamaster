# Автоматизирую повторяющуюся подготовку бизнес-отчёта

Соберу последовательность операций для регулярной выгрузки. Например, отберу оплаченные заказы, уберу дубли по согласованному ключу и подготовлю итог по продажам. Вместе зафиксируем контрольные суммы, чтобы следующую обработку можно было проверить за несколько минут.

## Что получит заказчик

- Настроенный сценарий с последовательностью операций.
- Обезличенный проверочный набор и готовый результат в согласованном формате.
- Короткую инструкцию для запуска на следующем файле и проверки промежуточных результатов.

## Что прислать

Пример исходного файла и готового отчёта, порядок ручных действий, названия группирующих полей и правила обработки возвратов. Отдельно отметьте случаи, когда строку нужно сохранить для ручной проверки.

## Как выглядит проверка

В демосценарии «Подготовка отчёта» источник содержит 864 заказа. Фильтр оставляет 720 оплаченных, затем сортировка поднимает наверх заказы с наибольшей суммой. Для вашей выгрузки аналогичным образом фиксируем число строк после каждого правила и проверяем итоговую сумму.

## Условия

Повторный запуск рассчитан на файлы с совместимыми столбцами и типами данных. Если один заказ содержит несколько товарных позиций, для удаления дублей нужен ключ позиции или составное правило. Обработка выполняется в браузере, сценарий запускается пользователем в открытой вкладке.
