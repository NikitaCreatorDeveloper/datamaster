# Проверка DataMaster Studio 2.0

Проверка выполнена 24 ноября 2026 года на Linux в Node.js 24.22.3 и системном Chromium 156.0.8078.79. Браузерные тесты запускались на собранных файлах Vite с политикой безопасности из `dist/_headers`. Использованы вымышленные данные и два временных локальных HTTPS-источника для проверки межсайтовых запросов.

## Контрольные примеры

- **Формулы и книга.** Все 11 заявленных функций проверены на заданных входных значениях. Проверены циклы, деление на ноль, ошибка синтаксиса, неизвестные функции, перенос ссылок с `$`, обновление зависимостей и относительные формулы после вставки строки. Создана и повторно прочитана книга с несколькими листами, включая пустой лист, формулы и их результаты, цвет, границы, шрифт, размеры, закрепление и условное правило.
- **Продажи.** В трёх строках тестового реестра общая выручка составила 300. После выбора канала A браузер показал выручку 250, расходы 160, прибыль 90 и рост 50%. Проверены три вида графиков и восстановление настроек панели. В скачанном PNG проверены формат и размер, из PDF извлечены кириллический текст, месяц и числовое значение.
- **Большая таблица.** В Chromium импортированы 50 000 строк. В DOM оставалось менее 60 строк таблицы. После прокрутки отредактирована последняя запись. Многошаговый расчёт остановлен, исходная правка сохранилась, применение незавершённого результата оставалось недоступным.
- **Конструктор.** Загружены реальный XLSX и CSV с разными заголовками. Сохранённое сопоставление восстановлено из JSON сценария после повторного входа в конструктор. Объединение, очистка и нормализация дали два независимых результата по артикулу и количеству. Проверены образцы после этапов, журнал, скачанный JSON и добавление итогового листа.
- **API.** Проверены CORS-отказ и разрешённый preflight на разных HTTPS origins, Bearer и пользовательский заголовок, параметры, JSON-тело, три страницы, ручное и периодическое обновление. POST, PUT, PATCH и DELETE дошли до локального получателя после подтверждения. Отмена в диалоге сохранила число полученных запросов. Обработан ответ 204 без тела. Проверено отсутствие тестового секрета в сохранённом шаблоне и очистка поля авторизации при возвращении на экран. Для курсорной пагинации, ограничения объёма и повреждённого JSON использованы управляемые ответы транспорта.
- **Проекты.** До согласия пользовательская база IndexedDB отсутствовала. После согласия проверены сохранение и восстановление листа с числом 42, активного проекта и экрана, экспорт, повторный импорт, удаление проекта и отключение хранения. При записи устаревшей вкладкой браузер показал конфликт, проект второй вкладки восстановился после перезагрузки.
- **Интерфейс и приватность.** Проверены русские и английские подписи, светлая и тёмная темы, мобильное меню, основные разделы при ширине 360 px, редактор при ширине 320 px. В проверенном маршруте с пользовательским файлом отсутствовали внешние HTTP-запросы. Текст с угловыми скобками отображался как содержимое ячейки. Для строк с формульным префиксом проверено экранирование CSV и текстовый тип при экспорте XLSX.

## Совместимость

| Область | Поддержка и границы |
|---|---|
| Excel | Формат XLSX. На листе одна строка заголовков. Сохраняются поддерживаемые формулы с результатом, имена вкладок, типы, основные стили, размеры и закрепление. Имена длиннее 31 символа, повторы и запрещённые Excel символы обрабатываются при экспорте. XLS, XLSM, макросы, изображения, внешние связи, объединённые ячейки и произвольные объекты оформления находятся вне модели редактора. Держите исходную книгу для полного оригинального оформления. |
| Формулы | Локальные A1-ссылки, прямоугольные диапазоны, `$`, английские имена функций, точка в десятичной дроби, запятая или точка с запятой между аргументами. Строка 1 содержит заголовки. Ссылки на другие листы, внешние книги, именованные диапазоны и формулы динамических массивов не поддерживаются. Неизвестная формула из XLSX импортируется по её кэшированному результату, при отсутствии кэша ячейка будет пустой. |
| Вычисления | VLOOKUP поддерживает точный поиск и приближённый для отсортированного справочника. XLOOKUP выполняет точный поиск и принимает необязательный результат для отсутствующего ключа. COUNTIF/SUMIF поддерживают одно равенство или сравнение, шаблоны с `*` и `?` не интерпретируются. Даты хранятся в ISO-виде, функции календаря и сериализация дат в формулах Excel находятся вне набора. Отличия в приведении типов, обработке дат, удалении границ диапазона и сравнении текста возможны. |
| Защита вычислений | До 4 096 символов в формуле. Вычислитель ограничивает глубину вложенности, цепочку зависимостей и общий объём вычисления. Ошибки отображаются в ячейках, в том числе `#CYCLE!`, `#REF!`, `#DIV/0!` и `#LIMIT!`. |
| Оформление | Цвета RGB, заливка, шрифт, жирное и курсивное начертания, простая граница, горизонтальное выравнивание и четыре типа правил по столбцу. Экспорт записывает эти правила как условное форматирование XLSX. При импорте распознаются полноразмерные правила выражений, созданные этой версией. Произвольные формулы оформления, темы Excel и сложные границы могут упроститься. |
| CSV и JSON | CSV читается как UTF-8, распознаются запятая, точка с запятой, табуляция и вертикальная черта. Значения CSV изначально текстовые, ведущие нули сохраняются. Табличный JSON — массив записей. Вложенные значения файла сериализуются в ячейку, API Studio отдельно разворачивает вложенные объекты. CSV/JSON экспортируют значения. Формулы и оформление хранятся в XLSX и JSON проекта. |
| Аналитика | Сумма, среднее, минимум и максимум учитывают числовые значения, количество считает непустые. Прибыль берётся из выбранного поля или из разницы выручки и расходов. Динамика сравнивает последние два присутствующих месяца с ненулевой базой. При отсутствии пригодных полей отображается прочерк. Диаграмма показывает до 36 групп и шести рядов, круговая использует первый ряд. Экран сводной показывает до 40 строк. PDF содержит всю сводную в пределах лимита. |
| API Studio | JSON по HTTPS c разрешением CORS. При локальной разработке также поддерживается свой HTTP origin. Для пагинации доступны номер страницы и курсор по JSON-пути, до 30 страниц. Тайм-аут отправки 30 секунд. Автообновление доступно для GET после первого переноса данных в лист. Интервал от 15 секунд. Скрытая вкладка пропускает такты, выход из API Studio останавливает обновление. Отзыв клиентского запроса не отменяет уже принятую внешним сервисом операцию. |
| Проекты и сценарии | Сохранение относится к браузеру, профилю и origin. Проект переносится специальным JSON с версией схемы. История отмены и API-учётные данные остаются в текущей сессии. В пакетном сценарии сохраняются шаги и схема сопоставления. Файлы нового пакета выбираются заново. После изменения структуры источника проверьте сопоставление. |

## Размеры и условия проверки

Один файл или весь ответ API ограничен 16 МиБ. При пакетном импорте суммарный вход составляет до 64 МиБ. На одном листе доступно до 100 000 строк, 300 столбцов и 1,5 млн ячеек. В одном проекте доступно до 150 листов и 3 млн ячеек. Для XLSX проверяются размеры распакованных записей центрального каталога. Поток обработки завершается по тайм-ауту 90 секунд. Доступная оперативная память устройства может понизить практический предел.

Изменение оформления или заполнение диапазона ограничено 100 000 ячеек за действие. История вмещает до 30 табличных действий с дополнительным ограничением объёма для крупных наборов. PDF ограничен 40 столбцами и 60 000 ячейками. Для полного сохранения крупной книги используйте XLSX или JSON проекта.

Браузерный прогон покрывает Chromium на Linux. Safari, Firefox, нативные мобильные браузеры и настольный Microsoft Excel в этом прогоне не запускались. XLSX независимо прочитан через ExcelJS. На управляемом компьютере прямой переход в `file://` заблокирован политикой Chromium. Автономность проверена с тем же единым HTML, доставленным как начальный документ, и последующим отключением сети. Пользователи с аналогичной политикой могут разместить файл в локальном каталоге и открыть его через `python3 -m http.server 8000 --bind 127.0.0.1`. Для API с авторизацией используйте HTTPS и разрешённый сервисом origin.

Сборка Cloudflare проверена по содержимому статического архива и браузерным сценариям на его ресурсах с заголовками из `_headers`. Публикация в аккаунте Cloudflare владельца описана отдельно. [Инструкция](CLOUDFLARE.md)
